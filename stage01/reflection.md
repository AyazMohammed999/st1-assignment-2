Before using AI, I built the print statements and the appointment 
functions myself, including the list of dictionaries used to store 
each booking. AI did not particularly help me understand how to use 
dictionaries and functions more clearly, since I had already worked 
through that structure on my own. AI did make assumptions when 
generating its version, such as adding a docstring and returning 
appointment data in a different way than my version did. I checked 
the AI's code by running it and comparing its output to mine, to see 
where the two versions matched or differed. I did not have much 
engineering work left afterward, as I had already tested edge cases 
and written the comparison table before finishing this reflection.
